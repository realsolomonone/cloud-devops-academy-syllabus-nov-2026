Kendops

07

Cloud, written down.

Cloud

  1. 01Capacity you can add, and remove, when demand moves.
  2. 02Identity, network rules, backups, and a budget.
  3. 03A managed service when running it yourself is not the work.

Infrastructure as code

  1. 01Infrastructure lives in Git, next to the application.
  2. 02A plan is reviewed before anyone is allowed to apply.
  3. 03State is protected. Secrets never enter the repository.

Commit → plan → review → apply → verify

10

AI drafts. People decide.

CodeExplain a failure. Draft a test. Write the note the next person needs.
OperationsGroup the logs. Name the likely cause. Do not page the room.
ServiceSort the request. Draft the reply. A person sends it.
ReleaseWrite the notes from the commits that actually shipped.

Guardrails

  1. 01Secrets never go into a prompt.
  2. 02Production and destructive actions wait for approval.
  3. 03Generated code and commands are read before they run.
  4. 04Permissions are narrow. Actions are logged. Rollback exists.
